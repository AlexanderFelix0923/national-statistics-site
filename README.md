**Atlas in Numbers** — a national statistics explorer covering 40 countries: population, GDP, life expectancy, density, connectivity and more. An overview with the population giants and regional rollups, a searchable and sortable explorer, a full page per country (stat grid with world ranks, population history since 1990, country-vs-average bars), top-10 rankings for twelve measures, and a three-country compare tray. Favourites and the compare tray persist locally; every chart is hand-drawn SVG and the whole site runs offline from static files. Figures are rounded public statistics for ~2024 (World Bank · UN Population Division · IMF).

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or open app/index.html directly
```
